WIE BLEIBT DER WALD FUNKTIONSFÄHIG?

Start:
1. Den Ordner vollständig auf ein Endgerät kopieren.
2. index.html im Browser öffnen.

Das Lernprogramm benötigt nur für das freiwillige YouTube-Video eine Internetverbindung.
Das Video wird über die Schaltfläche im Browser direkt auf YouTube geöffnet, weil eingebettete YouTube-Videos beim Start über eine lokale Datei häufig blockiert werden.
Alle übrigen Inhalte und Bilder funktionieren offline.

Der Lernstand wird lokal im Browser des verwendeten Geräts gespeichert.
Über „Lernstand zurücksetzen“ kann er gelöscht werden.

Erstellt für NW, Jahrgang 8.
